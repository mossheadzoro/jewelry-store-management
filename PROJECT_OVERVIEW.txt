1. TECH STACK

FRONTEND (client/):

  - Language:        TypeScript 5.8.3
  - React:           React 19
  - Styling:         Tailwind CSS 4.1.11 (with tw-animate-css)
  - UI Primitives:   Radix UI (Dialog, Select, Popover, Tabs, Tooltip, etc.)
  - Icons:           Lucide React, Tabler Icons React
  - Charts:          Recharts 2.15.4
  - Tables:          TanStack React Table 8.21.3
  - Forms:           React Hook Form 7.61.1 + Zod 4.0 + ArkType 2.1
  - State Mgmt:      Zustand 5.0.6 (global stores for branch/user)
  - Drag & Drop:     @dnd-kit (core, sortable, modifiers, utilities)
  - Date Utilities:  date-fns 4.1.0, React Day Picker 9.8.1
  - Toasts:          Sonner 2.0.6
  - Drawer:          Vaul 1.1.2
  - Excel Export:    xlsx 0.18.5
  - HTTP Client:     Axios 1.10.0 + native fetch
  - Auth:            NextAuth 4.24.11 (JWT strategy, credentials provider)
  - Fonts:           Geist Sans + Geist Mono (via next/font/google)

BACKEND (built into Next.js API routes):
  - ORM:             Prisma 6.11.1
  - Database:        PostgreSQL (hosted on Neon — serverless Postgres)
  - Connection:      PgBouncer connection pooling via Neon pooler
  - Auth Backend:    NextAuth with bcryptjs password hashing
  - File Storage:    Cloudflare R2 (S3-compatible) via @aws-sdk/client-s3
  - Image CDN:       Cloudinary (for product images)
  - File Uploads:    Multer 2.0.2, Formidable 3.5.4

SERVER (server/):
  - Minimal Node.js package (likely placeholder/future microservice)
  - Has its own package.json but no significant code

BUILD TOOLS:
  - PostCSS 8.5.6
  - ESLint 9 + eslint-config-next
  - ts-node (for seed scripts)

4. FULLY FUNCTIONAL FEATURES (What the app DOES do)
================================================================================

A) BILLING ENGINE & SALES
   - Creating Invoices: Dynamic rows with metal value auto-calculation based on live-entered gold/silver rates.
   - Taxation: Full GST computation (3% total, or split between metal and making charges), hallmark charge tracking.
   - Making Charges: Flat rate or percentage based, with discounts on making charges.
   - Payment Splitting: Accepting split payments across Cash, UPI, Card, NEFT, Cheque, Advance, and Metal simultaneously.
   - Old Gold Exchange: Auto-deducting pure gold equivalent from the bill total.
   - Excess Gold Settlement: Cash-out (returning cash to customer) or "Return Gold" ledger entries.
   - Interactive Edit: Invoices can be reopened and fully edited with state restoration.
   - Real-time Inventory Deduction: Selling a product automatically removes it from stock and updates the ledger.
   - Listing & Pagination: Fully functional invoice list with backend pagination and React Query caching.

B) INVENTORY & STOCK
   - Product Management: Creating products with dynamic categories (Gold, Silver, Diamond) and sub-categories (Rings, Chains).
   - Barcode/HUID Tracking: Auto-generating product codes.
   - Ledger: Real-time tracking of every stock movement (IN, OUT, SELL, EXCHANGE).
   - Dynamic Searching: Searching products by barcode or name directly in the billing screen.

C) CUSTOMER CRM
   - Registration & Management: Creating and editing customer profiles with PAN/Aadhar tracking.
   - Search & Lookup: Robust searching via mobile or name.
   - Transaction History: Viewing a customer's detailed purchase history, ledger, and outstanding balances.
   - Statistical Summaries: Calculating lifetime value, total outstanding, and determining VIP/Gold tiers based on spend.

D) METAL EXCHANGE (TONCH) & KARIGAR
   - Creating Tonch Sessions: Logging raw metal weights before and after melting to calculate purity.
   - Karigar Management: Maintaining a directory of artisans.
   - (Basic) Issuing Metal: Registering metal given to a karigar.

4.1 UI STUBS & NON-WORKING FEATURES (Buttons exist but logic isn't wired)
================================================================================

The following features have buttons, modals, or UI elements visible on the frontend, but the underlying backend API or logic is NOT YET IMPLEMENTED or is heavily stubbed:

1. Direct Communication / Messaging
   - *Where:* Customer Details Page -> "Message" button.
   - *Status:* The modal opens, templates can be selected, and a "Send" button exists. However, clicking send just triggers a 1.5-second visual mock delay and an alert. It does NOT integrate with Twilio, WhatsApp Business API, or any actual email service.

2. Exporting Data (Excel/PDF)
   - *Where:* "Export" buttons found on the Sales Invoices tab, Customer List, and Inventory screens.
   - *Status:* The UI buttons exist, but clicking them currently does nothing. No XLSX or PDF generation library is actively wired to these specific buttons yet.

3. Advanced Table Filtering
   - *Where:* "Filter" button next to search bars on most data tables (Sales, Customers).
   - *Status:* Clicking the button does nothing. Advanced multi-column filtering is not yet implemented on the backend.

4. Sales Reports & Analytics
   - *Where:* Sales Page -> "Reports" tab.
   - *Status:* The charts and summary cards often display static or highly simplified mock data. Full historic aggregation API endpoints are missing or incomplete.

5. Bulk Operations
   - *Where:* Sales Page -> "Bulk Operations" tab.
   - *Status:* The UI exists to select multiple invoices for bulk printing or deletion, but the backend bulk action endpoints are not fully wired.

6. Voice Recording Storage (Order Book)
   - *Where:* Order Creation -> Voice Note Recorder.
   - *Status:* The microphone records audio on the frontend successfully, but uploading and saving the `.webm` audio file to Cloudflare R2/Database upon form submission is not fully robust/implemented.

7. Karigar Wastage & Fine Gold Adjustments
   - *Where:* Karigar details -> Adjust Wastage modal.
   - *Status:* Forms exist, but the complex double-entry accounting for fine gold loss during manufacturing is not completely finalized in the database ledger.

8. Wholesaler Financial Settlements
   - *Where:* Wholesaler dashboards.
   - *Status:* The UI exists, but the backend double-entry system mapping wholesaler metal accounts against cash accounts is partially incomplete.
